AP5307 Outlook Rescue — Final Classroom Edition

UPLOAD TO GITHUB:
Only index.html is required. Replace the current index.html in the repository.

FINAL FEATURES:
- 9 missions + Boss Level
- persistent Back / Mission Map / Next navigation
- mission/stage status
- revisit completed missions without duplicate XP
- local browser progress saving and resume
- 65-minute timer
- team roles
- varied PBL interactions
- real Outlook challenges
- final competition result, completion time, XP and verification code
- Copy Result button
- Submit Result button prepared for a Microsoft Forms leaderboard

LEADERBOARD:
The game itself remains on GitHub Pages and stores progress only on each team's device.
To collect class results centrally, create a Microsoft Form and place its public response URL in:
const FORM_URL=""
inside the submitResult() function.
A simple form can ask for Team Name, XP, Completion Time, Completion Code, and optional screenshot.
Then display the Microsoft Forms/Excel responses on the projector.

No student credentials or confidential Outlook content should be entered into this public activity.
